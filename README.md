# Claudio Startrek Bridge Soundpack

Star Trek bridge-inspired sounds for Claudio.

## Install

```bash
claudio soundpack add gh:ctoth/claudio-soundpack-startrek-bridge --default
```

Or from a local clone:

```bash
claudio soundpack add /path/to/claudio-soundpack-startrek-bridge --name startrek-bridge --default
```

## Layout

This is a directory soundpack. The repository root contains Claudio sound
categories such as `loading/`, `success/`, `error/`, `interactive/`,
`completion/`, `system/`, and `default.mp3`.

## Source Notice

The sounds in this pack were assembled from the existing Claudio
`soundpacks/startrek-bridge` directory. The original in-repo manifest describes
the source as TrekCore.com.
